Índice Meteorológico de Incendios: FWI con transparencia y precisión

El Fire Weather Index (FWI) estima el peligro meteorológico de incendios a partir de temperatura, humedad, viento y precipitación. Aquí encontrarás explicación técnica y una calculadora online conectada a la API.

Transparencia

Implementación auditable y alineada con las definiciones del sistema canadiense.

¿Qué es el FWI?

El FWI es la salida del sistema canadiense CFFDRS. Usa tres códigos de humedad (FFMC, DMC, DC) y dos índices (ISI, BUI) para producir un valor adimensional que sintetiza propagación e intensidad potencial del fuego bajo las condiciones del día.

Este valor guía medidas de prevención de incendios forestales. Sirve para planificar patrullajes, informar a la población y organizar recursos en parques, bosques y zonas rurales de Argentina.

Componentes del sistema

FFMC — Fine Fuel Moisture Code

Mide la humedad del combustible fino: afecta ignición y propagación inicial. Sensible a HR, T°, viento y lloviznas.

DMC — Duff Moisture Code

Humedad del mantillo orgánico: integra condiciones de varios días, modula persistencia.

DC — Drought Code

Sequía profunda: tendencia de largo plazo y energía potencial disponible.

ISI / BUI / FWI
ISI = φ(FFMC, Viento)
BUI = ψ(DMC, DC)
FWI = ω(ISI, BUI)
